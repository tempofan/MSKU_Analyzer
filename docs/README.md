# MSKU表现分析器 📊

> **亚马逊MSKU配送费表现分析和利润报表校正工具**

## 🚀 快速开始

### 开发环境启动
```bash
# 安装依赖
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/

# 启动应用（推荐）
启动应用.bat

# 或使用Python脚本
python scripts\startup\run.py
```

### EXE版本使用
```bash
# 打包为EXE
scripts\build\打包为EXE.bat

# 运行EXE
双击 MSKU分析器_v1.0.0.exe
```

## 📁 项目结构

```
MSKU表现分析器/
```

## ✨ 主要功能

- 🔍 **订单利润分析** - 全面分析配送费表现
- 📊 **MSKU维度汇总** - 按MSKU统计利润数据
- 🛡️ **异常订单识别** - 自动识别特殊订单
- 🔧 **利润报表校正** - 三重校正机制
- 📈 **SKC维度统计** - 配送费异常检测

## 📋 文件要求

| 文件类型 | 来源 | 格式 | 必需性 |
|---------|------|------|--------|
| 订单利润报表 | ERP-财务-利润报表-订单 | Excel/CSV，表头第2行 | ✅ 必需 |
| Hual MSKU列表 | Hual产品清单 | Excel/CSV | ✅ 必需 |
| 产品资料表 | 产品管理系统 | Excel/CSV | ✅ 必需 |
| MSKU维度利润报表 | ERP-财务-利润报表-MSKU | Excel/CSV，表头第2行 | 📄 可选 |

## ⚠️ 重要注意事项

- 订单数据必须在美国旺季区间（10月15日-次年1月14日）
- 所有数据必须来自同一国家
- MSKU报表费用类型必须为"Order"
