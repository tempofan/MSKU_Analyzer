# MSKU表现分析器 - 部署指南 🚀

## 📦 EXE打包部署

### 快速打包
```bash
# 一键打包（推荐）
scripts\build\打包为EXE.bat

# 手动打包
python scripts\build\build_exe_for_colleagues.py
```

### 打包流程
1. **环境检查** - 验证Python版本和必要文件
2. **依赖安装** - 自动安装PyInstaller（如需要）
3. **构建配置** - 创建PyInstaller配置文件
4. **EXE构建** - 编译生成可执行文件
5. **发布包创建** - 整理文件并创建使用指南
6. **ZIP压缩** - 生成最终分发包


## 🔧 开发环境部署

### 环境要求
- Python 3.8+
- Windows 10/11 或 Linux/macOS
- 2GB+ 可用磁盘空间

### 安装步骤
```bash
# 1. 克隆或下载项目
cd MSKU表现分析器

# 2. 安装依赖（使用国内镜像）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/

# 3. 启动应用
启动应用.bat
# 或：python scripts\startup\run.py

# 4. 访问界面
# 浏览器打开 http://localhost:5000
```

### 高级配置
```bash
# 指定端口和主机
python scripts/startup/run.py --port 8080 --host 0.0.0.0

# 禁用调试模式
python scripts/startup/run.py --no-debug

# 查看版本信息
python scripts/startup/run.py --version
```

## 🌐 生产环境部署

### 使用Gunicorn（Linux）
```bash
# 安装Gunicorn
pip install gunicorn

# 启动应用
gunicorn -w 4 -b 0.0.0.0:5000 src.web.app:app
```

### 使用Docker
```dockerfile
FROM python:3.9-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/

COPY . .
EXPOSE 5000

CMD ["python", "scripts/startup/run.py", "--host", "0.0.0.0"]
```

### 使用Nginx反向代理
```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 🛠️ 故障排除

### 打包问题

**PyInstaller安装失败**
```bash
# 手动安装
pip install pyinstaller==6.3.0 -i https://pypi.tuna.tsinghua.edu.cn/simple/

# 升级pip
python -m pip install --upgrade pip
```

**构建失败**
```bash
# 清理重试
Remove-Item -Recurse -Force build, dist
python scripts\build\build_exe_for_colleagues.py
```

**文件缺失错误**
- 检查所有必需文件是否存在
- 确认文件路径是否正确
- 验证项目结构完整性

### 运行问题

**端口被占用**
- 程序会自动分配其他端口
- 手动指定端口：`--port 8080`

**依赖包问题**
```bash
# 重新安装依赖
pip install -r requirements.txt --force-reinstall
```

**权限问题**
- Windows：以管理员身份运行
- Linux：检查文件权限 `chmod +x`
