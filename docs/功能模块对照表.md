# MSKU表现分析器 - 功能模块对照表 📋

## 📊 模块功能概览

| 模块名称 | 主要功能 | 输入 | 输出 | 核心算法 |
|---------|---------|------|------|----------|
| 🔍 文件验证模块 | 验证文件格式和必需字段 | 用户上传文件 | 验证结果 | 格式检查、字段匹配 |
| 📖 数据读取模块 | 读取和解析各类数据文件 | Excel/CSV文件 | DataFrame对象 | pandas读取、表头识别 |

#### ⚙️ 计算算法
```python
def calculate_actual_shipping_fee(row):
    """
    配送费计算决策树：
    
    IF 买家运费 == 0:
        return FBA费
    ELIF 买家运费 + 促销折扣 == 0:
        return FBA费  
    ELSE:
        return 买家运费 + 促销折扣 + FBA费
        
    逻辑说明：
    - 买家运费为0：纯FBA配送
    - 买家运费+促销折扣为0：促销抵消后的FBA配送
    - 其他情况：复合配送费用
    """

def triple_correction_mechanism(msku_report, abnormal_fees, 
                               skc_min_fees, skc_min_costs, product_info):
    """
    三重校正算法：
    
    第一重：异常订单费用校正
    - 字段映射：异常订单字段 → MSKU报表字段
    - 校正公式：校正后值 = 原始值 - 异常费用

    - 获取SKC最低配送费

    - 计算公式：理想成本 = 最低均价 × (FBA销量 + FBA补换货量)  
    - 更新头程成本字段
    
    执行顺序：必须按1→2→3的顺序执行，确保校正效果累积
    """
```
