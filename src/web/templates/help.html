功能概述

MSKU表现分析器是一个功能强大的亚马逊订单利润分析与校正工具，主要功能包括：

订单分析
  • 识别VINE订单
  • 识别换货订单
  • 识别新品入仓优惠订单
  • 识别Hual订单
配送费计算
  • 计算实际配送费用
  • 考虑买家运费
  • 考虑FBA费用
  • 考虑促销折扣
数据校正
  • 校正MSKU维度利润报表
  • 修正异常订单费用影响
  • 进行理想校正
  • 一致性检查
分析报告
  • 生成详细分析报表
  • MSKU维度汇总
  • 异常订单统计
  • 费用一致性检查

计算规则说明
实际配送费计算
  1. 当买家运费 = 0时：
    实际配送费 = FBA费
  2. 当买家运费 > 0时：
    • 如果买家运费 + 促销折扣 = 0
      实际配送费 = FBA费
    • 否则
      实际配送费 = 买家运费 + 促销折扣 + FBA费
特殊订单识别
  • VINE订单：
    销售额 = 0 且 FBA费 ≠ 0
  • 换货订单：
    销售额 = 0 且 FBA费 = 0
  • 新品入仓优惠订单：
    FBA费 = 0 且 销售额 > 0
  • Hual订单：
    基于Hual MSKU列表匹配
  • 二手商品订单：
    MSKU前4个字母为"amzn"的订单

常见问题

请确保文件格式为CSV或Excel格式（.csv, .xlsx, .xls）。如果仍然无法上传，请检查：

  • 文件是否损坏
  • 文件大小是否超过50MB
  • 文件名是否包含特殊字符

可能的原因包括：

  • 源文件中缺少相应的列
  • 列名不匹配（请确保使用标准的列名）
  • 数据格式问题（如日期格式、数字格式等）

建议检查源文件的列名和数据格式。

处理时间取决于文件大小和数据量。如果处理时间过长：

  • 请耐心等待，不要关闭浏览器
  • 可以尝试分批处理大文件
  • 检查网络连接是否稳定

一般情况下，处理10万条记录需要2-5分钟。

我们采取以下措施保护您的数据：

  • 所有文件仅在服务器临时存储，分析完成后自动删除
  • 数据传输采用HTTPS加密
  • 不会保存或备份用户上传的敏感数据
  • 建议在使用后及时下载结果文件

这是因为配送费结构不同：

  • 美国市场在旺季(10月15日00:00-次年1月14日23:59)和淡季收取不同的配送费率
  • 为确保配送费分析的准确性，分析器要求所有订单都在同一费率周期内
  • 混合不同费率周期的订单会导致配送费计算和比较错误，影响分析结果
  • 支持纯旺季或纯淡季订单分析 - 您可以分别上传旺季订单或淡季订单进行分析
  • 如需对比旺季和淡季表现，请分别进行两次分析

重要：本限制仅适用于美国市场，其他市场无此限制。程序同样支持淡季订单分析。
